# tell_me_story

Учебное занятие: ученики называют ИТ‑термины, а затем коллективно сочиняют историю,
используя эти термины. Скрипт автоматически подсчитывает баллы и ведёт таблицу.

## Суть
1. **`words.txt`** — словарь терминов. Каждая строка: `термин (Имя)`, где термин —
   одно слово или словосочетание. За каждый внесённый термин ученик получает **2 балла**.
2. **`story.txt`** — история. Предложения идут друг за другом (через точку), каждое
   оканчивается именем автора в скобках: `... (Имя)`. За **каждое употребление** термина
   в предложении автор предложения получает **3 балла**.
3. **`chart.txt`** — итоговая таблица баллов в виде полосок.

## Файлы
| Файл | Назначение |
|------|------------|
| `autoedit.py` | фоновая программа (главный скрипт) |
| `words.txt` | словарь терминов (`термин (Имя)`) |
| `story.txt` | история (предложения с `(Имя)` автора) |
| `chart.txt` | таблица баллов (генерируется) |

## Как запустить
```
python autoedit.py
```
Скрипт работает в фоне: каждые 2.5 секунды проверяет `words.txt` и `story.txt`,
обновляет файлы и выводит живую таблицу баллов в консоль. Остановка — **Ctrl+C**.

## Принципы работы
- **Проверка использования терминов.** Скрипт ищет термин в истории **по началу слова**
  (без учёта регистра), поэтому склонения и окончания не мешают: `байт` находит
  `байта`, `байтов`; `нейросеть` — `нейросети`. Для словосочетания все его слова
  должны встретиться в предложении.
- **Пометка галочкой.** В `words.txt` перед уже использованным термином ставится `✅`.
  Неиспользованные термины записываются выше использованных (сортировка по галочке).
  Файл `story.txt` при этом не изменяется.
- **Баллы.** 2 балла — за внесение термина в `words.txt`; 3 балла — за каждое
  употребление термина в предложении (автору предложения).
- **Таблица баллов.** `Имя: ███ 5` — полоска пропорциональна баллам. Строки
  отсортированы по убыванию баллов. Полоски цветные (ANSI) и выводятся в консоль.

## Настройка (константы в начале `autoedit.py`)
| Константа | Назначение |
|-----------|------------|
| `POLL_INTERVAL` | частота проверки, сек (по умолчанию 2.5) |
| `POINTS_FOR_TERM` | баллы за внесение термина (2) |
| `POINTS_FOR_USE` | баллы за употребление термина (3) |
| `USE_COLORS` | цветные полоски в `chart.txt` |
| `PRINT_CHART_TO_CONSOLE` | вывод таблицы в консоль |
| `CLEAR_SCREEN` | очистка экрана перед отрисовкой таблицы |
